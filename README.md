# ToxiCrew

Página de chat básica donde mandas mensajes de texto y grabas audios.

## Archivos principales:
- `index.html`: La estructura de la página.
- `enviarMensaje.js`: Para mandar mensajes de texto.
- `animacionAudios.js`: La interfaz y grabación de audios.
- `popUp.js`: El popup para confirmar si borras un audio.
- `grabarAudio.js`: Función para empezar a grabar audio.
- `styles.css`: Los estilos.

## Funcionalidades:
- Mandar mensajes con la hora.
- Grabar audios (necesita permiso del micro).
- Confirmación para borrar audio mientras grabas.
- ID único para cada usuario (guardado en localStorage).

## Notas:
- Para banear usuarios de verdad, hace falta un backend para guardar la lista de baneados. (luego lo hago)
- Los mensajes se van al recargar la página.
- Necesita imágenes en `imagenes/` y audios en `audios/`.
